# v0.6.2 空正文修订验收

日期：2026-11-27。Windows 10 x64（19045）、Python 3.10.0、PySide6 6.8.3、PyInstaller 6.22.3。用户明确确认单日手写可以为空，本次修订覆盖旧计划中的正文必填限制。

## 行为

- 空正文、仅空格/换行/制表符归一为空；正文与出处都空时生成留白日历，只有出处时显示出处。
- 非空正文只有标点仍提示修改；原始输入中的非法 XML 控制字符继续拦截，包括会被 strip 移除的非法控制字符。
- 正文标明可选，摘要显示“留白日历”或“仅出处”。清空输入后可以直接预览、生成，沿用原有缓存与任务控制。
- 清单字段不变，空正文且无语料编号的页面可恢复，空白页不参与跨日期正文去重；带语料编号缺正文仍报错。CSV 输入及语料库导入保持原规则。
- 省略空正文元素，B/G 不显示孤立装饰引号；仅出处的共享文字块不附加正文分隔线，原几何版式保留。
