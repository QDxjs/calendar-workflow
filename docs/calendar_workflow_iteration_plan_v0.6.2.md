# v0.6.2 空正文修订计划

日期：2026-11-27。用户确认单日手写应允许空正文，本修订覆盖 v0.6.1 文档中的正文必填约束。

- 允许正文、出处均为空；只含空格/换行/制表符时归一为空，生成留白日历；仅填出处时保留出处。非空正文只含标点仍提示修改，非法 XML 字符仍拦截。
- 单日手写沿用原有计划缓存、随机试排、首张预览及导出路径；界面正文标记为可选，摘要显示“留白日历”或“仅出处”。
- 清单字段不变：空正文与空 quote_id 表示无语料正文，允许重复日期以外的多张空白页恢复。带非空语料编号却缺正文仍报告清单错误。CSV 输入与 JSON/JSONL 语料导入维持原有规则。
- 共享文字块省略空正文；仅出处不附加正文分隔线；B/G 留白页省略孤立装饰引号，保留原几何风格。
- 验收覆盖九版空白/仅出处 PNG、多日期清单无损恢复、历史识别、桌面缓存与预览/导出一致、空白页灯箱及普通语料回归。
- 单独构建 v0.6.2，保留旧版目录及 ZIP；最终解包运行包清单与 366 页全年自检。

本轮不包含日期选择器、分类、精确排版等其他能力；后续方向仍见 ROADMAP。实际结果见 [验收记录](validation_v0.6.2.md)。

完成状态：实现及便携包已完成，82 项测试通过；最终 ZIP 解包副本通过 283 项包文件校验和 366 页全年自检。交付 v0.6.2 目录、ZIP 及 SHA-256，未覆盖旧版交付物。
