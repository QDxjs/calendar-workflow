最终 ZIP 的验证进程仅保留 Windows 系统 PATH，并移除 `PYTHONHOME` 和 `PYTHONPATH`；这证明便携运行不依赖系统 Python 搜索路径，但不等同于在未安装 Python 的干净目标机验收。

网页检查需要 Chromium 子进程。当前沙箱禁止其命名管道，测试在获准的沙箱外离屏进程运行；没有浏览外部网页。软件渲染的 GPU 回退提示不影响检查结果。离屏 Qt 界面截图显式加载系统已有的 Segoe UI/微软雅黑字体以避免该离屏环境的字体发现限制，不向发行包添加字体。

## 尚未覆盖与保留边界

- 本机只有 Python 3.10，Python 3.12 需 CI 验证；已为 CI 加入独立 Chromium 检查，但尚未推送触发。
- 未在全新、未安装 Python 的 Windows 系统上运行，未逐一验证 Edge/Chrome，也未更改真实系统缩放到 125%/150%。离屏缩放和截图不能替代这些验收。
- 新大图交互仅用于新生成或从清单恢复的网页；不会修改旧网页。恢复沿用当前模板、字体和渲染器，不承诺旧版本像素复现。
- 日期选择器、类别筛选、CSV 桌面导入、代表页编辑、磁盘示意缓存、精排和并发仍是后续候选，不计入本版完成范围。
