# v0.6.1 评估与实施计划

日期：2026-11-27。基线为当前工作区 v0.6.0 实现，保留已有改动；本轮直接完成开发、回归与便携包验证，不自动提交或发布。

## 评估结论

采纳单日手写与历史扫描收口，保持清单字段、原子发布及语料库导入契约不变。手写与语料库分别校验，不为引入来源抽象而重写现有语料库生成路径。

修正文档中的假设：

- 版式可容纳性由九种实际 SVG 渲染器试排确定，不能按显式行数硬编码 A/E。
- 正文内部换行保存在计划与 CSV 中；现有模板仍会重新平衡视觉断行，精确诗歌排版延期。
- 版式 B 空出处时省略其出处横线与 SOURCE / CITATION 标签，保留其余几何设计。
- 输入时只做轻量文本校验；预览或生成时试排，失败结果按内容键缓存并在对应字段提示。
- 历史时间标注为“清单更新时间”，使用本机时区，不推断生成时间。
- 不以提交旧版或无法取得的外部环境验收阻塞本轮开发；未验证环境如实列出。

## 开发任务与验收

1. Qt 无关手写规划：边界校验、空出处、实际试排筛选、固定种子复现，返回标准不可变计划。
2. 独立手写面板：单日约束、内存草稿、字数软提示、字段错误、任务锁定；预览与导出复用同一计划。
3. 历史优化：单次 CSV 解析收集版本，兼容旧 prepare_replay 接口，清单时间安全回退。
4. 回归：九版 SVG/PNG、超长/控制字符、换行/出处缓存失效、模式切换、取消/失败恢复、清单无损恢复、离线网页转义。
5. 版本与交付：同步 v0.6.1 文档与打包自检，执行全套测试、发布文件检查、桌面与网页视觉检查、解包隔离 PATH 自检并提供 SHA-256。

本轮不新增日期选择器、CLI 参数、并行渲染、磁盘缓存或精确排版引擎。Python 3.12、无 Python 的独立 Windows、实际 Edge/Chrome 与真实系统缩放若无条件验证，应保留为验收限制。

## 实施结果

以上五项已完成：78 项测试、公开文件与资源检查、源码/便携桌面自检、离线 Chromium 及窄窗口离屏检查通过。新版 ZIP 的独立解包副本通过 283 项文件哈希校验与 366 页全年自检，包含新增手写工作流；未提交或公开发布。交付物与环境边界见 [验收记录](validation_v0.6.1.md)。
