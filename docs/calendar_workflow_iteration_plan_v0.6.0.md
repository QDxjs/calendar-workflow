# Calendar Workflow v0.6.0 评估与开发计划

评估日期：2026-11-26
源码基线：v0.5.7，提交 `1316ba4`
目标版本：v0.6.0（建议）
状态：v0.6.0 核心功能已实现；当前验证与环境限制见 [发布交接](../RELEASE_HANDOFF.md)

## 1. 评估依据

本计划评估用户提供的《每日文学日历 · Calendar Workflow 版本迭代规划文档》（文件名 `calendar_workflow_iteration_roadmap.md`），并与当前源码、测试、[现有路线图](../ROADMAP.md)、[发布交接](../RELEASE_HANDOFF.md)交叉核对。原文保留不变，本文作为收敛范围后的执行计划。

本文最初交付为评估和开发计划。用户随后要求立即开发，已按 F1–F4 实施 v0.6.0；后文保留计划及当时基线记录，实际结果以发布交接和本轮验证记录为准。代码、便携包与公开发布是不同阶段，未自动推送或发布。

## 2. 总体判断

原文识别了真实问题，也覆盖了主要演进方向，但不能直接作为单个版本的开发清单。其 v0.6.0 同时包含模板修复、设置迁移、日期控件、历史管理、多页计划编辑、磁盘缓存、分类、两类 CSV、网页浏览、打印、并发和状态机重构，变更面横跨几乎全部核心模块，缺少统一验收及拆版条件。

建议将 v0.6.0 定位为：**修正输出内容，完成“生成 → 重启后找回 → 大图回看 → 清单恢复”的日常闭环**。

- P0：年份与日序号、便携版输出目录记忆、历史批次、离线网页灯箱与月份筛选、兼容及发行验收。
- 后续 0.6.x 候选：日期快捷选择、分类、CSV 语料导入、示意缓存、只读代表页抽样。按反馈择项交付，不一次性承诺。
- v0.7.0 候选：统一字体与精确排版。并发加速先做性能实验，再决定是否纳入独立版本。
- 更远期候选：PDF、画幅、主题、农历节气、逐日编辑、壁纸及跨平台，各自形成专项需求，不与“迈向 1.0”捆绑交付。

## 3. 原文结论核对与修正

| 原文判断或建议 | 核对结果 | 执行决策 |
| --- | --- | --- |
| B、E 版式写死 2027 | **已复现**。生成 2026/2028 年时，B 仍含 `VOLUME 2027`，E 仍含独立 `2027` 标签 | P0 修复，补跨年测试及 A–I 视觉回归 |
| A–E 的静态 001 都是错误 | 静态文字属实，但“日编号”和“版本/系列号”的语义需区分 | 日相关标签统一使用现有 `ordinal`；`EDITION`、`SERIES` 不做无差别替换 |
| 需新增 `batch_index/batch_total` | 当前 `metadata()` 已提供 `ordinal/year_days` | 本版选年积日，无需扩展清单，也避免同一天因批次截取不同而改变编号 |
| 便携版不记输出目录 | **代码确认**。启动和保存偏好均受 `frozen` 分支限制 | P0 统一读取/保存用户显式目录，新增恢复默认行为 |
| 首张预览缺少代表页与版式比较 | **属实**，但窗内切换版式会影响整批内容计划语义 | 延后。先定义只读抽样与计划编辑的边界 |
| 版式示意每次启动需重渲染 | **属实**，现有缓存仅在窗口内存 | 延后。缓存键不能只使用程序版本，需覆盖渲染资源和字体环境 |
| 可直接勾选内置类别 | 原始文件保留分类，但 `builtin_quotes()` 返回的记录只有 `quote/source/quote_id` | 需要调整加载入口，不能只在界面加复选框 |
| 桌面 CSV 可复用现有 CSV 导入 | `csv_inputs.py` 面向日期任务，要求 `date,quote,source,layout`；语料诊断面向 `name/from` | 必须区分“语料 CSV”和“日期任务 CSV”，不能同一入口静默忽略日期/版式 |
| 历史列表读取首页生成时间 | 当前 manifest 每行记录页面，且没有独立生成时间列；只读首行无法得出总页数和完整范围 | 解析清单得摘要。生成时间未知时不伪造；可明确显示目录修改时间 |
| 历史扫描必须同时有 manifest 和网页 | 这会隐藏仍可恢复、但网页缺失的批次 | 以 manifest 为候选依据，网页/图片作为独立状态 |
| 英文和数字被硬拆、显式换行可能被破坏 | **代码确认并有函数级样例**。`wrap_text()` 按字符切分，`balance_quote_lines()` 可跨原显式行移动字符 | 作为排版专项，先积累样例；本版不顺带更换折行算法 |
| 正文/出处存在碰撞 | 缺少几何碰撞检测属实；本次尚未复现具体压框输入 | 记录为待复现风险，不把所有版式描述为已发生碰撞 |
| 并发可提升 2–3 倍且即时取消 | 串行子进程属实；倍数无基准。当前 `subprocess.run()` 在单页执行中不能因取消标记立即终止 | 不承诺倍数。并发和中断子进程均先设计、测量及验证 |
| 拆分 1045 行 desktop 可降低风险 | 文件为 1045 行属实；同时拆状态机并叠加功能仍会扩大回归面 | 只做功能必需的局部提取，不预先重写主窗口 |
| 旧清单可无损、100% 恢复 | 当前可恢复已记录内容与实际版式，但使用当前模板、字体和渲染器，不能保证原始像素一致 | 区分“内容恢复”和“像素复现”；新增主题等参数也不自动解决资源版本问题 |
| 当前标准尺寸为精确 4:5 | 实际尺寸为 1122 × 1402，只是接近 4:5 | 保留既有像素规范；未来画幅元数据用准确宽高而非近似比例 |

## 4. v0.6.0 范围与验收标准

### F1. 动态年份和日编号（P0）

**实现**：修改 `calendar_layout_b.py`、`calendar_layout_e.py` 的固定年份；逐项审查 A–E 的日相关标签，以 `m["ordinal"]` 格式化为三位数。`metadata()` 已有年积日，不新增批次序号和 manifest 列。

**编号约定**：`ENTRY`、`DAY`、`NO.`、`ARCHIVE`、表示每日阅读的 `READING / ...` 作为日相关标签；`EDITION 001`、`SERIES 01` 保留系列/版本含义，并在代码中明确。不能搜索替换所有 `001` 或 `01`。

**验收**：

- B/E 在 2026、2028 年的日期标签不残留错误年份；覆盖 2028-02-29、年末及跨年范围。
- 1 月 1 日为 001，2028-02-29 为 060，2028-12-31 为 366；同一天单独生成或随批次生成编号一致。
- A–I 的 SVG 和 PNG 能实际生成，1122 × 1402、命名和 manifest 字段不变。
- 恢复旧清单得到原内容及实际版式；明确本版模板修复会改变相关旧页面的恢复像素。

### F2. 输出目录记忆与恢复默认（P0）

**实现**：复用 `preferences.py` 的用户级 `settings.json` 及原子写入机制，统一源码与便携版行为。本版只持久化输出位置，不同时自动加载外部语料或增加所有控件记忆。

- 未保存自定义位置时，便携版默认目录仍根据当前 EXE 位置计算，避免移动便携包后沿用旧安装位置。
- 用户显式选择的绝对目录可记住；源码版已保存的 `output_directory` 继续读取，无需强制迁移。
- “恢复默认目录”清除显式覆盖，回到当前运行方式的默认值。
- 记住的目录暂时不可用时保留选择并显示诊断，允许改选；不静默切换后继续生成。
- 设置损坏时可启动并提示；设置写入失败仅影响下次记忆，不使本次可写目录失效。
- 偏好写入需保留其他已知/未知字段，使用同目录临时文件和原子替换；自检及测试不写真实用户设置。

**验收**：便携版更改目录后重启可恢复；重置后可随 EXE 移动；旧设置兼容；不存在、不可写及设置损坏均可从界面恢复；保存位置变化不使现有内容计划失效。

### F3. 历史批次与恢复（P0）

**模块**：新增 `batch_history.py`（无 Qt 的发现/解析/状态服务）、`history_dialog.py`；局部调整 `desktop.py`。

- 打开历史窗口时，扫描当前输出根目录的直接子目录；支持另选历史位置及刷新，不在启动时递归扫描整盘。
- 含 `manifest.csv` 的非隐藏目录作为候选；跳过暂存目录和发布锁。直接选择一个含清单的批次目录亦可查看。
- 后台解析完整清单，复用 `prepare_replay()` 的内容校验；不渲染、不修改清单、不新增持久化历史索引。
- 摘要显示批次名、日期范围、页数、实际版式摘要、种子、应用版本及文件状态。无生成时间时显示“未知”，或另列“目录修改时间”。
- 页面以“日期 + 实际版式”标识，不能仅按日期去重；现有九版式测试包含同日多版式。
- 网页缺失、部分图片缺失或清单损坏分别诊断。清单有效但网页缺失时仍允许恢复；损坏清单显示原因并禁用恢复。
- 操作包括打开网页、打开文件夹、恢复到新目录。每次重新检查目标文件，路径按已校验日期与版式构造。
- 将 `_choose_replay()` 中选定清单后的逻辑提取为共享方法；复用原权限检查、唯一目标目录、后台生成、取消和进度。
- 扫描有独立结果通道、请求编号和取消标记，关闭/换目录后丢弃旧结果；不复用生成队列及取消事件。
- 生成和生成前预览期间禁用新开历史入口；历史查看结束后再启动恢复，避免扩大同时运行任务的状态组合。
- 查看历史不要求源目录可写，不自动打开浏览器，不改主窗口输出位置；多位置聚合、删除、重命名不在本版。

**验收**：重启后能找到既有批次；只读批次能查看；网页缺失仍能恢复；损坏记录不拖垮列表；恢复不覆盖原批次；取消扫描及恢复均无残留或迟到更新。

### F4. 离线网页大图与月份筛选（P0）

**模块**：增强 `gallery.py`，补充网页结构回归及浏览器验收。按原文选择网页灯箱方案，本版不额外开发一套 Qt 整批图片浏览器。

- 点击图片在当前页面显示大图，支持上一张/下一张、方向键、Esc、关闭按钮、适应视口及原始尺寸。
- 保留 SVG/PNG 下载链接；无 JavaScript 时原图片链接和下载仍可用，初始化失败不影响基础页面。
- 跨月时提供 `YYYY-MM` 月份筛选；与搜索、版式筛选组合。跨年相同月份不能合并成一个“1 月”。
- 灯箱只在当前筛选结果中导航，保持确定顺序；筛选变化后若当前页不在结果中则关闭大图，零结果有提示。
- 不一次性解码全年原图；缩略图继续懒加载，大图按需切换。
- 键盘焦点进入灯箱，关闭后回到触发元素；正文/出处按文本处理，保持现有 HTML 转义。
- 自包含 HTML/CSS/JS，不引入 CDN，不从 `file://` 发起依赖服务器的取数请求。
- 本版先不增加版式统计和打印分页承诺。浏览器打印样式不等于印刷级 PDF，后续单独定义。

**验收**：本地 `file://`、断网下工作；组合筛选/首尾页/零结果/跨年月份/键盘/原图/下载正确；关闭返回原列表；旧版本生成的网页仍原样保留，新版不批量改写历史网页。

v0.7 的字体精排也需先验证度量与实际 resvg 渲染使用同一字体及 shaping 规则，不能将 Qt 度量结果直接视为 resvg 像素真值。字体许可、包体和回退策略在选型时核对；本计划不替未来字体包作许可结论。

## 7. 测试矩阵与发布门槛

### 7.1 必须新增或扩展的自动测试

- **模板**：跨年年份、普通/闰年序号、同日不同批次一致、同日多版式、SVG 文本转义与 PNG 校验。
- **偏好**：旧设置、空/损坏文件、自定义/默认目录、EXE 移动、目录失效、设置写入失败、不写真实用户设置。
- **历史**：空目录、多批次、隐藏暂存与锁、旧清单、缺字段/错误日期/错误版式/不一致种子、无网页/缺图、只读源、扫描中删除、取消和迟到结果。自动扫描不意外跟随目录联接访问根目录外的内容。
